Moderation, tickets, activity, music, and media tools

PHPelefant keeps Discord servers organized without getting in the way.

A production-minded Discord bot for staff teams that need moderation logs, ticket workflows, anti-abuse tools, XP profiles, image utilities, music playback, and owner-only operations.

Core Systems

  • Advanced moderation and audit logs
  • Dropdown or button ticket panels
  • Welcome embeds and DM onboarding
  • XP, levels, profiles, and leaderboards
  • Music playback with FFmpeg and yt-dlp
  • Owner shell and deployment controls

Invite

Replace CLIENT_ID with the bot application ID from the Discord Developer Portal. 

https://discord.com/oauth2/authorize?client_id=CLIENT_ID&permissions=8&scope=bot%20applications.commands

For user-installed commands in DMs and group chats, enable user installation in the Discord Developer Portal and keep the applications.commands scope enabled.

Deployment

  1. Create the bot in the Discord Developer Portal and copy the token.
  2. Install dependencies with pip install -r requirements.txt.
  3. Install FFmpeg for music playback.
  4. Set DISCORD_TOKEN, BOT_OWNER_ID, and DATABASE_URL in .env.
  5. Run python -m phpelefant_discord.main.

Terms Of Service

PHPelefant is provided as a community management tool. Server owners are responsible for configuring permissions, moderation policies, and third-party media usage according to Discord rules and local law. Abuse of owner-only shell, broadcast, or moderation controls is not supported.

Privacy Policy

PHPelefant stores Discord IDs, usernames, server IDs, moderation actions, warnings, ticket metadata, activity counts, XP, and configuration needed to operate the bot. Ticket transcripts are generated only when staff or users request them. Database backups should be treated as private operational data.
